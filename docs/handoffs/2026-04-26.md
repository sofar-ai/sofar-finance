## Lessons captured

1. **ADR-0011 / V2**: Schema verification rule is insufficient without
   programmatic enforcement. Pattern hit 4 times in 2 days despite an ADR.
2. **Renaissance frame applied to building**: don't compress horizons.
   Bundle 7 deserves fresh attention; today shipped enough.
3. **Substrate-as-canonical is real**: pricing, model definitions, node
   roles, all canonical in DB, not memory or hardcoded SQL.
4. **Sed for code is dangerous**: mac1 rename caused several regex artifacts
   (duplicated `mac1|mac1`, self-mapping aliases). Use Python edits for
   semantic-structure files, sed only for plain config.
5. **Continuity protocol works**: this handoff plus bundle 7 spec plus the
   substrate state should let next session bootstrap cleanly. ADR-0006's
   four-layer pattern is being tested.
