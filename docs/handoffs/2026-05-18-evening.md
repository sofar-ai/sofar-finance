## Three measurement bugs documented in ADR-0028

1. **1.403 fiction** — `lgbm-predictor.py` hardcoded a `portfolio_sim` dict containing `{'sharpe': 1.403, ...}` that was never computed. Propagated across monolithic, per-asset, aggregator, v8 sim comparisons all session. Fixed by deletion + dynamic load.

2. **Walk-forward Sharpe over-annualization** — `lgbm-predictor.py` uses `np.sqrt(252)` to annualize per-trade Sharpe with horizon=7/14/21 returns. Inflates by sqrt(horizon). Reported 3.636 (7d) / 4.372 (14d) / 4.892 (21d) → real ~1.37 / 1.17 / 1.07 after correction. Acknowledged but NOT yet patched in `lgbm-predictor.py` (production retraining behavior unchanged).

3. **Per-trade Sharpe independence violation** — overlapping forward windows make consecutive trades non-IID. Per-asset predictor's `sqrt(252/horizon)` annualization on 252 trades/year reported Sharpe 5.104 for SPY γ 14d. Non-overlap protocol (every 14th trade) gives 1.537. Documented as the project's measurement standard going forward.
